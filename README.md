## How it works

```
141 build cards (67 fields each)
       │
       ├──► Anti-Crowd Score ──► DOMINATE / ENTER / WATCH / IGNORE
       │         (26 strategies × 25 dimensions)
       │
       ├──► Contradiction Arbitrage ──► breakthrough prediction + confidence
       │         (138-node graph, PageRank, 1783 edges)
       │
       └──► Epistemic Drift ──► concept velocity + bridge concepts
                 (PMI matrix, 43 cross-domain bridges)
```

## Why it exists

- **Where is everyone wrong together?** ACS scores how empty or crowded a strategy zone is — the short-interest of strategic positioning
- **What are two experts saying that cancels out?** CAR finds contradictions between competing strategies and scores the arbitrage gap
- **What word no longer means what it meant?** Drift detects vocabulary/concept drift over time — when a term has shifted meaning
